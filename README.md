# To-Do List App

A simple Flutter application for managing a to-do list with offline capabilities using Hive.

## Features

- Add, update, and delete tasks.
- Mark tasks as complete.
- Display the creation date of each task.
- Search for tasks.
- Offline storage using Hive.
